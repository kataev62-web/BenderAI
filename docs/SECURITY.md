# Безопасность и модель угроз

По умолчанию: офлайн-провайдер, нет записи, нет скриншотов, нет облака, нет UI control и записи файлов; чтение папки Загрузки разрешено для офлайн-сценария. Приложения запускаются только по встроенным ID notepad/calculator/explorer, абсолютными системными путями. Администратор/UAC обходы не предусмотрены.

План модели/импортированный навык — недоверенные данные. Ни один из них не может выдавать разрешения, добавлять инструменты или исполнять произвольный Python/shell. `eval`, `exec` и `shell=True` не используются. Нет инструментов удаления файлов, отправки писем, финансовых операций или изменения системных настроек. Автозапуск HKCU изменяется только пользователем в настройках.

Проверяется каждый шаг. Чужие каталоги и symlink/junction-выходы через существующий путь исключаются canonical-path проверкой; совпадение префикса строки не считается разрешением. Read/write/UI/execute/network разделены. Создание папки и UI-изменения требуют просмотра плана и одноразового подтверждения. Режим наблюдателя блокирует изменения. Права на исполняемые навыки не выдаются навсегда: подтверждение требуется на каждый запуск.

GUI выдаёт права только после явного выбора окна, просмотра пути EXE, выбора чтения/управления и подтверждения. Новые права ограничены точными заголовками и путём процесса; управление задаётся отдельно по каждому окну. Legacy-разрешения сохраняются без автоматического расширения. Браузеры/консоли требуют отдельного адаптера, повышенные приложения исключены. UIA требует ровно одного совпадения, не использует fuzzy matching и сохранённые координаты. Пароли исключаются до чтения значения, неизвестное IsPassword блокируется. Приватные окна по известным маркерам заголовка исключены; это дополнительная защита, не универсальный детектор приватности. Не выдавайте доступ чувствительным приложениям через редактирование базы.

Запись — UIA Invoke/ValueValue/SelectionItem/Toggle/ExpandCollapse события только выбранных деревьев окон в отдельном процессе. Переходы сохраняются как ожидание/фокус; перед записью события проверяется foreground и принадлежность точному дереву. Нет клавиатурных хуков, фонового захвата экрана, чтения буфера обмена. По умолчанию вместо текста сохраняется `${value_1}`. Значения при воспроизведении и ошибки внешних сервисов в журнал не попадают. Если вы **явно** выбрали запись буквального текста, он сохраняется в навыке и его JSON-экспорте; используйте только несекретные значения. Универсально распознать секрет в обычном поле нельзя.

Cloud выключен до выбора пользователем и согласия, ключ сохраняется только Windows Credential Manager, HTTP endpoint обязан использовать HTTPS. Перенаправления запрещены, TLS не отключается. Передаётся только новая команда и описание схемы инструментов: без скриншотов/истории/UI-дерева. Срок сетевого запроса ограничен 30 сек.; кнопка Стоп сбрасывает его результат, но уже отправленный запрос не отзывает. Ollama — только loopback, модели автоматически не скачиваются.

Скриншот требует нового согласия, выбора экрана и места сохранения каждый раз; single-use право затем снимается. OCR и автоматический cloud-vision отсутствуют.

Gradle разрешается отдельно для конкретного проекта, нативного java.exe, установленной Gradle и списка задач. Запуск Java аргументами без .bat/.cmd/shell, с `--no-daemon`; Windows Job Object завершает дочернее дерево при отмене. Build-скрипты сами являются исполняемым кодом: используйте **только доверенные проекты**, это сильная привилегия. Гарантировать безопасность чужого Gradle-проекта приложение не может.

Отмена кооперативная между локальными операциями; COM изолирован и прекращается при отмене. Уже нажатую кнопку/созданную папку невозможно отозвать. При сбое — остановка, не слепой повтор. По умолчанию 0 повторов. 100 шагов, 120 секунд на запуск, 60 секунд ожидания, запись до 5 минут. Аудит без аргументов/ключей, ограничен 10 000 событий, запуски — 2 000. Из GUI можно очистить историю и удалить навыки. Локальная SQLite не шифруется: защита профиля Windows/диска остаётся необходимой. Ключ API в SQLite не хранится.

Не является границей изоляции от злоумышленника с теми же правами Windows, подменой бинарников/окон или конкурентной заменой каталогов. Публичный выпуск требует Windows-приёмки, проверки зависимостей, подписи дистрибутива и отдельного аудита.

Подробные ограничения межоконной записи, диагностика и приёмка: [MULTIWINDOW_LEARNING_RU.md](MULTIWINDOW_LEARNING_RU.md).
