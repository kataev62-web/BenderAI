# Межоконное обучение UIA

Пользователь разрешил самостоятельную реализацию без цикла согласований. Сохраняем Python 3.12/PySide6, существующую SQLite и изоляцию COM. Ветка разработки отделена от ECC-ветки.

Выбран путь расширения точного UIA: список разрешений по исполняемому файлу и точным заголовкам, выбор нескольких окон, подписка только на их деревья. Другие варианты — глобальная запись ввода или координатное воспроизведение — не удовлетворяют ограничениям безопасности и не применяются. Браузерам/нестандартным контролам нужен отдельный проверяемый адаптер; универсальная запись не заявляется.

Каждое действие содержит app/window/AutomationId/type/parents. При переходе добавляются wait_for_window с ограниченным временем и focus_window. Состояния Toggle/ExpandCollapse воспроизводятся идемпотентно; SelectionItem выбирается точно. Повторные изменения текста коалесцируются только подряд для того же элемента, текст по умолчанию заменяется параметрами. Пауза/СТОП исключают задержанные события по perf_counter. До чтения значения исключаются password/неизвестный password-status, чужие деревья и приватные окна. Поддержка контролов проверяется по UIA patterns, отказ виден без сохранения их текстов. Известные опасные кнопки остаются заблокированы; запуск любого изменяющего плана требует отдельного подтверждения помимо выдачи разрешения приложению.

Редактор показывает приложение, окно, элемент и значение/состояние; существующие импорт/экспорт/версии сохраняются. Разрешения сохраняются в settings, навыки/параметры — существующими skill_versions; миграция схемы не требуется. UIA вызовы остаются в отменяемом дочернем процессе; отсутствие/неоднозначность окна и смена заголовка не разрешаются fuzzy-поиском.

Проверки: сначала RED в pytest для маршрутизации и отказов, затем GREEN; отдельные UI-тесты; реальный Windows CI с несколькими процессами тестовой формы, переключением foreground, записью и повторным запуском; упаковка/проверка замороженного EXE. Тестовые двойники, нативный CI и ручная Windows-приёмка отчитываются раздельно. Никаких скрытых хуков или доверия ECC hooks.
