1. Выполнить интерактивные tests/test_windows.py и ручные A–J на Windows 10/11. Сейчас код UIA/COM и нативная форма написаны, но Windows-запуск не подтверждён.
2. Выполнить Windows CI, собрать и испытать ZIP/оба exe на чистом профиле. Убедиться в упаковке generated COM typelibs, доступности Credential Manager и корректной работе spawn в frozen приложении.
3. Проверить события ValueValue/Invoke на нативных Edit/Button, порядок событий и поведение паузы/остановки. Учебный цикл в Linux проверен только на Qt, не на UIA.
4. Проверить трей, глобальные сочетания/конфликты, маску окна и click-through, несколько мониторов/DPI, отключение дисплея, перемещение курсора и закрытие во время COM-операции.
5. Проверить реальную Ollama с установленной моделью, облачный OpenAI-совместимый сервер и Windows Credential Manager. Локальный HTTP-контракт/ошибки/редиректы покрыты тестами, реальных API-запросов не было.
6. Проверить утверждённый реальный Gradle/JDK-проект на Windows и остановку дерева процессов; Linux проверяет тот же механизм утверждённого нативного subprocess на Python, не успешную сборку Java-проекта.
7. Проверка лицензий фактически упакованных зависимостей, сборки с воспроизводимыми артефактами, подпись дистрибутива/решение о публичном имени и лицензии собственного кода.

## Сознательные границы 0.1

- Нет универсального зрения/OCR, голосового интерфейса, browser-adapter/Playwright, обхода CAPTCHA/UAC, доступа к приватным браузерным сессиям.
- Только точные UIA-селекторы и Edit/ValuePattern, Button/Invoke; нет координатного fallback, drag-and-drop и поддержки любого сайта/приложения.
- Нет удаления/перемещения/сортировки файлов; домашний режим пока ограничен безопасным чтением/открытием/созданием папок.
- Нет автоматического полноэкранного детектора, планировщика, фонового автономного режима, самоизменения кода и интеграции с Kingdom/ЕТС.
- Нет GUI-конструктора произвольных сложных сценариев: основные шаги редактируются формой/таблицей, продвинутые добавляются через строго валидируемый JSON.
- Нет инсталлятора MSI, подписи кода, платежей, магазина, лицензионного сервера, 3D и ресурсов «Футурамы».
- Нет бессрочного разрешения навыку: каждый изменяющий запуск подтверждается. Сетевой запрос уже отправленного провайдера не отзывается; Стоп отбрасывает результат.

Следующие направления после подтверждения основного цикла: дополнительные адаптеры контролов и браузера, надёжные assertions/параметры, OCR по явному разрешению, голос и собственные визуальные пакеты, затем коммерческие функции. Эти пункты не считаются реализованными.
