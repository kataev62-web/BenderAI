# Руководство

## Первый запуск и управление

Запустите `python -m bender_ai` или собранный `BenderAI.exe` из полной папки дистрибутива. Персонаж — оригинальный робот. Перетаскивание меняет позицию; обычный клик открывает чат. В трее доступны чат, обучение, пауза, стоп, настройки, скрытие и выход. Закрытие чата при наличии трея скрывает окно; «Выход» завершает приложение. Если трея нет, закрытие завершает приложение после остановки операций.

Настройки: размер, скорость, восемь состояний анимации, закрепление, «Не мешать» (пропуск кликов/сон), характер ответов, автозапуск (выключен), выбор провайдера и глобального стопа. Начальная позиция у нижнего края доступной области; при отключении монитора позиция ограничивается оставшимися экранами. Qt использует логические DPI-координаты. Режим наблюдателя запрещает изменения.

Персонаж не определяет полноэкранные игры автоматически: скройте его через трей. Для восстановления click-through персонажа используйте трей → «Настройки». Пакет PNG меняется в настройках; структура описана ниже.

## Офлайн и разрешения

Ввод команды → «Предложить план» → просмотр → «Выполнить показанный план». Отправка команды не исполняет действия. Повторный клик не запускает вторую задачу. Шаги и результат видны в чате/строке состояния; журнал содержит статусы без введённых значений.

Папки разрешаются отдельно на чтение и создание вложенных папок. Создание папки требует одноразового подтверждения. Обход за пределы разрешённого корня запрещён. Удаления, перемещения и сортировки файлов в этой версии нет.

Для активного окна сначала разрешите поддерживаемый процесс во вкладке «Разрешения». Во время запроса окно чата кратко скрывается, чтобы Windows вернула фокус предыдущему приложению; после выполнения появляется снова. Если предыдущее окно не разрешено или UIA не поддерживается, будет ошибка. Ничего не распознаётся «наугад».

В MVP разрешаются Блокнот и учебная форма. Современный Блокнот может предоставлять Document/TextPattern вместо Edit/ValuePattern: такая версия не поддерживается для записи/ввода; используйте учебную форму. Приложение не заявляет универсальную автоматизацию браузеров.

Скриншот — отдельная кнопка во вкладке «Разрешения». Каждый снимок требует согласия, выбора экрана и пути; отправки в облако нет.

## Обучение и проверка

Полный пример — в README. Учебная форма:

| Контрол | AutomationId | Тип |
|---|---|---|
| Name | 1001 | Edit |
| Greet | 1002 | Button |
| Статус | 1003 | Text |
| Password (всегда исключён) | 1004 | Edit |
| Move button | 1005 | Button |

UIA-запись начинается только после подтверждённой подписки и красного индикатора. На паузе события отбрасываются, в том числе задержанные. Нет сохранения потока нажатий клавиш. Изменения одного Edit объединяются до последнего текста. По умолчанию сохраняются параметры, а не значения. Если разрешена буквальная запись, не вводите секретные данные.

После остановки открывается таблица. Можно изменить имя, параметры, шаги, удалить/переставить шаги и добавить проверки. Двойной клик редактирует поля шага. Проверки: `exists`, `enabled`, `visible`, `text:точное значение`. Для устойчивой проверки результата выберите **статус** формы, не просто существование нажатой кнопки.

«Показать план» и «Выполнить» загружают план в чат, но ничего не запускают автоматически. «Проверить» требует хотя бы одного assert_element; после явного запуска сохраняет success/failed для выбранной версии. Это не сертификат безопасности — проверяйте содержимое шага. Неудачное выполнение останавливается, следующие шаги skipped. При изменении селектора исправьте его через редактор и подтвердите новую версию. Откат также создаёт новую версию.

Импорт JSON проходит строгую валидацию, не выдаёт разрешений и ничего не запускает. Экспорт содержит только имя/параметры/шаги, без настроек ключа, истории и прав. Буквальный текст самих шагов экспортируется. Для полной резервной копии **закройте приложение**, скопируйте `%LOCALAPPDATA%\BenderAI\memory.db` в безопасное место. API-ключ хранится Windows отдельно.

## Провайдеры

Офлайн работает сразу. Для Ollama самостоятельно установите сервер и модель; endpoint фиксирован на loopback `127.0.0.1:11434`, модель задаётся в настройках. При недоступности сервера выберите offline: GUI не блокируется. Автоматической загрузки моделей и скрытого переключения в облако нет.

Для OpenAI-совместимого облака задайте HTTPS endpoint `/v1/chat/completions`, имя модели, ключ (ввод Password), включите network и подтвердите переключение. Ключ записывается только в Windows Credential Manager, сервис `BenderAI`, пользователь `cloud`. Удалить ключ можно в «Диспетчере учётных данных» Windows. В чат ключ вводить не нужно. Реальная доступность модели/API зависит от вашего сервиса. В текущей среде реальный облачный API не проверялся.

## Gradle

«Разрешения» → «Разрешить проект и задачу Gradle»: доверенная папка проекта, JDK java.exe, установленная Gradle с `lib/gradle-launcher-*.jar`, точные имена задач `test,build`. Подтвердите исполнение доверенного build-кода. Gradle запускается через Java без shell/батников и без daemon. Затем в редакторе JSON можно добавить шаг:

```json
{"action":"launch_approved_gradle_task","args":{"project_path":"C:\\Work\\Project","task":"test"}}
```

Модель может предложить такой шаг, но не сможет утвердить новый проект/задачу. Интеграция конкретно с Kingdom не создана. JDK/Gradle в поставку не включены, запуск реального Gradle в Linux-сессии не проверялся.

## Локальный character pack

Папка содержит `manifest.json` и PNG:

```json
{
  "schema": 1,
  "animations": {
    "idle": ["idle.png"], "walk": ["walk1.png", "walk2.png"],
    "thinking": ["thinking.png"], "talk": ["talk.png"],
    "working": ["working.png"], "success": ["success.png"],
    "error": ["error.png"], "sleep": ["sleep.png"]
  }
}
```

От 1 до 60 кадров на состояние, до 2048×2048 и 4 МБ на PNG. Только файлы внутри выбранной папки; скрипты не загружаются. Маска окна ориентирована на стандартную фигуру робота; пакеты со значительно иным силуэтом могут обрезаться. Пакеты с чужими ресурсами не входят в проект и не распространяются.

## Проверка перед использованием

В Windows выполните шаги A–J из исходного ТЗ `docs/REQUIREMENTS_RU.md`. Особое внимание — ввод/запись/пароли, перенос кнопки, несколько экранов с разным DPI и работа глобального стопа. Неподдерживаемые UIA-контролы не означают, что приложение готово к автоматизации конкретной программы.
