# Локальные фразы и синтез голоса BENDER AI

**Для личного прототипа.** Программа не скачивает и не содержит аудиозаписей из «Футурамы». Используйте только файлы, которыми вы вправе пользоваться; не публикуйте чужие звуковые дорожки в GitHub или сборках.

## Подготовка — без программирования

1. Создайте локальную папку, например \`C:\Users\<вы>\Music\Bender-Private\`.
2. Положите в неё звуковые фрагменты в формате **WAV PCM, 8 или 16 бит, 8000–48000 Гц, моно или стерео, до 20 секунд каждый**. Максимум 80 WAV; размер каждого — до 8 МиБ.
3. Самый простой вариант — назвать файлы по ключевой реакции: \`привет.wav\`, \`пока.wav\`, \`спасибо.wav\`. При появлении соответствующего слова в ответе Бендера будет звучать выбранный файл, затем **синтезируется весь ответ**.
4. В BENDER AI: «Управление → Настройки» → включить «Озвучивать ответы (локально)» → «Режим голоса: Локальные WAV-реплики + синтез речи» → «Выбрать папку WAV» → «Прослушать WAV» → сохранить.
5. Выберите в настройках «Локальный ИИ — Ollama», затем нажмите **«Поговорить»** и спросите: «Привет! Как дела?». Чат остаётся отдельным от команд управления компьютером.

Если подходящей фразы нет, воспроизводится только обычный синтез речи. Для синтеза нужен установленный в Windows **русский голос SAPI5**. Если русского голоса нет, фрагмент WAV может прозвучать, но синтез остального текста выдаст понятную ошибку; это не замена лицензированному голосу персонажа.

### Необязательные точные соответствия

Файл \`manifest.json\` в той же локальной папке:

\`\`\`json
{
  "schema": 1,
  "clips": [
    {"file": "greeting.wav", "triggers": ["привет", "здравствуй"]},
    {"file": "farewell.wav", "triggers": ["пока", "до встречи"]}
  ]
}
\`\`\`

С манифестом имя WAV может быть любым, но только в выбранной папке. При совпадении нескольких ключевых фраз выбирается наиболее длинная. Если \`manifest.json\` отсутствует, слова автоматически берутся из имён WAV до двойного подчёркивания (\`привет__01.wav\` → \`привет\`).

Программа не слушает микрофон, не считывает другие приложения и не собирает фразы из видео. Перед выполнением операций на ПК по-прежнему требуется обычный отдельный план и подтверждение.

### Если оригинальный аудиофрагмент в MP3

Нужно локально конвертировать его в WAV, например через установленный FFmpeg:

\`\`\`powershell
ffmpeg -i "input.mp3" -ac 1 -ar 22050 -c:a pcm_s16le "привет.wav"
\`\`\`

Готовые WAV и manifest остаются **только на вашем ПК**. В GitHub загружается исключительно код поддержки частного звукового пакета.
