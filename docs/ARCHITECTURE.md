# Архитектура 0.1

Python 3.12+, PySide6 6.8.3, SQLite, pywinauto UIA и pywin32 на Windows. Единственный экземпляр — QLockFile в каталоге данных. GUI — основной Qt-поток; планирование/исполнение — один QThread; Windows COM — изолированный дочерний процесс с IPC и жёстким таймаутом. Учебная Win32-форма — отдельный процесс. Автозапуск выключен.

```text
Русская команда → AIProvider → Plan/Step (строгая схема)
                                    ↓
                       предварительный просмотр в GUI
                                    ↓
                  подтверждение → Executor → ActionRegistry
                                    ↓             ↓
                             SQLite-журнал    Policy → OS/UIA

Явная запись → события UIA выбранного окна → Recorder
                     ↓
          редактируемые шаги/параметры → подтверждение
                     ↓
          SQLite skill_versions → тот же Executor
```

## Границы модулей

- `models.py`: закрытый набор инструментов, типы Selector/Step/Plan, лимиты, разрешённые параметры только в текстах UIA. Неизвестные поля/инструменты отклоняются. Импорт и ответы модели проходят один валидатор.
- `brain.py`: Protocol AIProvider, локальный RuleBasedProvider, loopback Ollama и OpenAI-совместимый HTTPS CloudProvider. Только структурированные данные; никаких действий ОС. Перенаправления HTTP запрещены.
- `security.py`: read/write roots, приложения read/UI control, дополнительные ограничения по заголовкам окон, проекты и задачи execute, network, single-use screenshot; Windows Credential Manager без текстового fallback.
- `actions.py`: валидация целого плана перед первым действием, последовательный исполнитель, отмена, общий лимит 120 с, ожидания до 60 с, максимум 100 шагов, 0 автоматических повторов. Статусы шагов и результат проверки сохраняются. UIA не выполняет координатный fallback.
- `windows.py`: known folder API, активное окно, точный UIA-поиск по процессу/окну/ID/типу/родителям, Invoke/ValuePattern. События UIA только выбранных деревьев: Invoke, ValueValue, SelectionItem, Toggle, ExpandCollapse; пароли и неизвестный password-status исключены. Нет клавиатурного/мышиного глобального перехвата.
- `isolation.py`: сериализованный spawn/Pipe RPC для Windows-адаптера, максимум 12 с на запрос; при отмене/зависании процесс уничтожается и восстанавливается при следующем запросе. Запись имеет отдельный дочерний процесс, подписка снимается при завершении.
- `learning.py`: конечный автомат записи/паузы/отмены, выбор 1–12 окон, явные ожидания/фокус при переходах, диагностика причин, исключение чужих окон, коалесценция изменений Edit, параметры вместо значений по умолчанию. Временные метки исключают задержанные события из интервала паузы.
- `storage.py`: schema v1, settings/permissions в JSON, skills/skill_versions с планами, runs/run_steps, audit_events, chat_sessions (зарезервирована, содержимое чата не сохраняется). Шаги нормализованы внутри версий JSON. Атомарные транзакции и блокировка SQLite для потоков. Откат создаёт новую версию. Схема новее v1 не перезаписывается. Незавершённые запуски после сбоя отмечаются interrupted.
- `character.py`: оригинальный программный 2D-робот, восемь состояний, Qt logical coordinates/DPI, плавное движение и clamp экранов, drag, маска/пропуск кликов; валидируемые локальные PNG character packs.
- `app.py`, `editor.py`, `infrastructure.py`: русские экраны чата/навыков/разрешений/журнала, редактор шагов без кода, настройки, трей, workers, горячая клавиша; GUI связывает сервисы, провайдеры не получают Policy для изменения.
- `qt_training.py`: реальный in-process адаптер **только переносимых тестов Qt**, не подмена Windows UIA в production.
- `training_form.py`: стандартные нативные Win32 Edit/Button/Static с ID 1001/1002/1003; password 1004; перемещение кнопки 1005.

## Расширение

Новый инструмент требует закрытой схемы, policy-check, реализации адаптера и тестов. Новый провайдер возвращает Plan; он не получает права исполнения. Skill pack — schema=1 JSON, без разрешений и автозапуска. Character pack — данные PNG, без импортируемого кода. Платёжные ограничения не реализованы; новые тарифы/модули могут подключаться на границе providers/registry/UI, не меняя формата ядра.

Таймаут/отмена не откатывают уже совершённые действия. Каталоги в Policy принадлежат пользователю; это не sandbox против других процессов с его правами. Gradle — намеренно отдельная сильная привилегия для доверенного локального кода, не разрешение модели генерировать shell.

Новая межоконная запись: [дизайн](design/MULTIWINDOW_LEARNING.md), [инструкция/ограничения](MULTIWINDOW_LEARNING_RU.md). Разрешения добавляют app_paths и ui_window_scopes к settings JSON, schema SQLite остаётся v1.
